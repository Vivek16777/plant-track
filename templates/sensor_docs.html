Telemetry Hardware Configuration Instructions

This workspace supports streaming telemetry data from actual physical microcontrollers (e.g. ESP32, ESP8266, NodeMCU) or simulated environments (such as Wokwi). Follow these steps to map hardware variables into the prediction dashboards.

1. Recommended JSON Telemetry Format

Your ESP32 microcontroller should send HTTP POST requests with a raw JSON payload containing the following keys:

{
    "plant_id": 1,          // Required. The primary ID of the crop in the system.
    "temperature": 26.5,    // Optional. Floating point air temperature in °C.
    "humidity": 62.0,       // Optional. Floating point relative air humidity in %.
    "soil_moisture": 52.3,  // Optional. Normalized soil moisture percentage (0-100%).
    "soil_ph": 6.8,         // Optional. Soil pH rating (0.0 to 14.0).
    "light_intensity": 5400,// Optional. Light reading in Lux.
    "rain_level": 0.0,      // Optional. Precipitation indicator (0 for dry).
    "water_tank_level": 85.5// Optional. Water reservoir capacity percentage (0-100%).
}

2. Arduino C++ ESP32 Sketch Blueprint

Here is a clean template using WiFi and HTTPClient libraries to publish crop data every 10 seconds:

#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>

const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
const char* serverUrl = "http://YOUR_SERVER_IP:8000/api/telemetry";

const int plantId = 1; // Map this to your active registered crop's ID

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi Connected!");
}

void loop() {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(serverUrl);
    http.addHeader("Content-Type", "application/json");

    // Gather sensor readings (DHT22, capacitive moisture, etc.)
    float temp = 26.5; 
    float hum = 60.0;
    float moisture = 52.0;

    StaticJsonDocument<200> doc;
    doc["plant_id"] = plantId;
    doc["temperature"] = temp;
    doc["humidity"] = hum;
    doc["soil_moisture"] = moisture;

    String jsonPayload;
    serializeJson(doc, jsonPayload);

    int httpResponseCode = http.POST(jsonPayload);
    Serial.print("HTTP POST Status: ");
    Serial.println(httpResponseCode);
    http.end();
  }
  delay(10000); // 10-second sampling cycle
}
