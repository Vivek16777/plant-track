Convolution Filters

3×3 kernels slide over the input image, learning to detect specific features like edges, curves, and textures.

⚡

ReLU Activation

Introduces non-linearity to the network, enabling it to learn complex patterns beyond linear transformations.

📊

Max Pooling

Reduces spatial dimensions by taking maximum values, lowering computation while preserving dominant features.

🧠

Fully Connected

Dense layers compute high-level feature combinations, mapping extracted patterns to classification decisions.

🎯

Softmax Output

Converts raw scores to probability distribution across all classes, with the highest probability indicating the predicted class.
